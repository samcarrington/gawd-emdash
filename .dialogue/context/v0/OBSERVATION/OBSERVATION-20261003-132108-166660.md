The user reported EmDash 1.1.0's deployment warning that no Astro session driver was configured and that signed-in users are stored in Astro sessions, making admin sign-in fail without a driver. The Vercel adapter supplies no default session driver; Turso and S3 do not substitute for session storage. The original specification omitted this requirement, which was acknowledged and corrected. Build success without this driver was therefore not evidence of working administration. Source: https://docs.astro.build/en/guides/sessions/.
