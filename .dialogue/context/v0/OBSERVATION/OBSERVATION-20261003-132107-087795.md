The reviewed Vercel Blob API uses @vercel/blob, not an S3-compatible endpoint, despite its S3-backed infrastructure. It cannot simply replace the endpoint supplied to EmDash's s3 adapter. The current signed-URL documentation includes issueSignedToken and presignUrl with raw presigned PUT, making an EmDash custom adapter plausible without necessarily replacing the admin uploader. The illustrative Blob snippet was documentation-verified, not compiled or exercised. A complete adapter would need upload/download/delete/exists/paginated list/public URL/signed upload methods, stable paths and overwrite semantics, stream/metadata/error mapping, scoped expiring PUTs, CSP/CORS upload-origin integration and runtime authentication without browser-visible write tokens. Source: https://vercel.com/docs/vercel-blob/vercel-signed-urls.
