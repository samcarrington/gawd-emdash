Assistant technical choice within the approved packaging fix: add a Vercel-only post-enforced Vite configuration hook that filters @libsql/kysely-libsql out of an array-valued ssr.external list, set ssr.noExternal for that dialect, and alias the exact @libsql/client import to its supported @libsql/client/web export. The narrow filter retains other external packages. The web client supports remote libsql/HTTP(S)/WS(S), not local files; ordinary Node development already uses EmDash's sqlite adapter and is unaffected. This avoids unused native SQLite bindings without altering the local storage path.
