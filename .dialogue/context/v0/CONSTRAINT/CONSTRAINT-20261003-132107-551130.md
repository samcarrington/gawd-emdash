Proposed S3 operational baseline, not provisioned or audited in this session: private bucket, Block Public Access enabled, ACLs disabled, least-privilege bucket-scoped IAM, approved-origin CORS for signed PUTs and optional versioning. Omit S3_PUBLIC_URL initially so EmDash serves private media through its authenticated server-side storage access. A future media-only CloudFront/private-origin delivery path must not expose backup objects, including any backups/ prefix. Both @aws-sdk/client-s3 and @aws-sdk/s3-request-presigner are explicit application prerequisites. Missing S3 configuration must fail with EmDash's documented MISSING_S3_CONFIG rather than silently using local files on Vercel. Source: https://docs.emdashcms.com/deployment/storage/.
