Unresolved feature-equivalence constraint: EmDash's Node scheduler assumes a continuously running process and handles scheduled publication, plugin tasks and maintenance; Vercel functions cannot be treated as that process. Turso/S3 and Autobuild alone do not preserve this behaviour. The reviewed runtime contains runScheduledTasks, but the reviewed docs did not establish a supported ready-made Vercel HTTP bridge. Before acceptance, verify a supported integration point and implement/test a protected bridge with concurrency control and observability, or obtain explicit approval to reduce scheduled/maintenance scope and arrange alternatives. No bridge or scope reduction was approved or implemented. Vercel Cron needs an endpoint that actually invokes the batch and checks the CRON_SECRET bearer header. The reviewed Hobby limits were daily execution with hourly precision, versus minute schedules on Pro/Enterprise; a suitable plan or authorised external scheduler is needed for minute-level publication. Source: https://docs.emdashcms.com/deployment/nodejs/.
