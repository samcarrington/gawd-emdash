Proposed release safeguard: take a restorable database backup before migrations. Rolling back application code does not undo schema changes; where backward compatibility is unavailable, restore a matching database/application pair. A deployment must not cancel an in-flight migration merely to replace it with a newer release. Backup creation, restoration and a production rollback were not performed or tested in this session.
