Proposed operational safeguard in the specification, not independently provisioned or verified: isolate Production and Preview/staging Turso databases, media buckets and Upstash session stores. Previews must not mutate production resources. Configure EMDASH_SITE_URL as the exact public HTTPS origin for the environment, without an application path. For preview admin access use a stable staging alias or a tested exact-origin strategy; a production origin on arbitrary preview URLs can break passkeys and CSRF, and broadly accepting *.vercel.app is not a safe shortcut. Place Vercel functions near the Turso primary and S3 region rather than assuming the default region is suitable.
